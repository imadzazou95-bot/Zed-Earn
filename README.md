# ⚡ Zed Earn

منصة تسويق بالعمولة (Affiliate Marketing) متكاملة للجزائر. تطبيق ويب تقدمي (PWA) يعمل على الهاتف والكمبيوتر.

## 🚀 المميزات

- ✅ تسجيل وتسجيل دخول برقم الهاتف الجزائري
- ✅ OTP / رمز تأكيد SMS
- ✅ Onboarding تفاعلي (3 خطوات)
- ✅ دليل المستخدم مع Scrollspy
- ✅ إكمال الملف الشخصي + رفع صورة Avatar
- ✅ قائمة مهام متنوعة (سهل / متوسط / صعب / VIP)
- ✅ صفحة تفاصيل المهمة + رفع إثبات الإنجاز
- ✅ نظام KYC (التحقق من الهوية)
- ✅ محفظة إلكترونية + سجل المعاملات
- ✅ سحب الأرباح (CCP / محافظ إلكترونية / بطاقة بنكية)
- ✅ كود إحالة (Referral)
- ✅ نظام المستويات (مبتدئ → نشط → محترف → VIP)
- ✅ لوحة المتصدرين
- ✅ إشعارات داخلية
- ✅ دردشة الدعم الفني
- ✅ وضع التاجر
- ✅ الوضع الليلي / النهاري
- ✅ تصميم متجاوب (Responsive)

## 🚀 كيفية التشغيل

1. استنسخ المستودع:
```bash
git clone https://github.com/yourusername/zed-earn.git
```

2. ادخل إلى المجلد:
```bash
cd zed-earn
```

3. افتح `index.html` في المتصفح أو استخدم خادم محلي:
```bash
npx serve .
# أو
python -m http.server 8080
```

4. افتح `http://localhost:8080` في المتصفح

## 📱 كيفية الاستخدام

1. افتح التطبيق في المتصفح على هاتفك
2. انتظر شاشة البداية (Splash)
3. اقرأ دليل المستخدم (Onboarding)
4. سجّل برقم هاتفك الجزائري
5. أكمل ملفك الشخصي
6. ابدأ بقبول المهام وكسب العمولات!
